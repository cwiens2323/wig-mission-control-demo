# WIG Mission Control — Public Synthetic Demo

This repository contains a **static product-review demo** of WIG Mission Control.

- All displayed records are synthetic and de-identified.
- No internal Playbook files, SQLite database, credentials, or client data are included.
- Demo form entries and setting changes stay in the reviewer's browser (`localStorage`).
- This is not the authenticated operational pilot and does not provide shared persistence.

The operational pilot remains private until authentication, hosting, backups, and data-governance requirements are approved.
